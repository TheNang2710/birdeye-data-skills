## How to Use These Workflows

Each workflow follows the same structure:
1. **What it does** — one-line summary
2. **When to use** — decision criteria
3. **Inputs** — what you need to provide
4. **Step-by-step** — exact clicks/commands
5. **How to read the output** — field-by-field explanation
6. **CU cost** — expected credit usage
