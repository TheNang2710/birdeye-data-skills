# Workflow: Trending List (Skill #1)

## What it does
Fetches the hottest tokens by volume/rank/liquidity. Use it to discover what's moving right now.

## When to use
- You want to find trending tokens quickly.
- You're looking for volume spikes or new listings.
- As a starting point for further DD.

## Inputs
- **Chain** (sol / bsc / base / eth)
- **Sort by**: rank / volume / liquidity
- **Interval**: 5m / 15m / 1h / 4h / 24h
- **Platform** (optional): filter by pump.fun, moonshot, etc.

## Step-by-step

### 1. Open Trending List
Go to **🔥 Discovery → Skill #1 · Trending List**.

### 2. Configure
- Choose **Chain** and **Interval** (24h for daily trends, 5m for momentum).
- Choose **Sort by** (volume for most active, liquidity for safest).

### 3. Run
Click **Run**.

### 4. Read the output
- Table of tokens: symbol, price, 24h volume, liquidity, market cap, holders, rank.
- Click any token to open Token DD (Skill #3) for deeper analysis.

### 5. Save & reuse
- Auto-saved to **History**. Replay for 0 CU.
- Copy CLI command with 📋 button.

## CU cost
- **Run**: ~30 CU
- **Replay from history**: 0 CU
