# Workflow: Token DD (Skill #3)

## What it does
The flagship "Should I buy this token?" check. Combines overview, money flow, security, and smart-money data into an A/B/C/D/F/NG rating with a 0–10 score.

## When to use
- You found a token and want a comprehensive buy/no-buy verdict.
- You want to compare multiple tokens side by side.
- As the first step before deeper due diligence.

## Inputs
- **Token address**
- **Chain** (sol / bsc / base / eth)

## Step-by-step

### 1. Open Token DD
Go to **🛡 Token Due Diligence → Skill #3 · Token DD**.

### 2. Enter the token
- Paste the token contract address.
- Choose **Chain**.

### 3. Run
Click **Run**.

### 4. Read the output
- **Grade**: A / B / C / D / F / NG with a numeric score (0–10).
- **Key metrics**: price, volume, liquidity, market cap, holders.
- **Security flags**: mint/freeze authority, LP lock, taxes.
- **Smart money**: SM wallet activity.
- **Money flow**: net inflow/outflow.

### 5. Save & reuse
- Auto-saved to **History**. Replay for 0 CU.
- Copy buttons for address and CLI command.

## Grade Cheat Sheet
| Grade | Score | Action |
|-------|-------|--------|
| A | ≥ 8.5 | Strong buy candidate |
| B | 7.0–8.4 | Good, with minor risks |
| C | 5.5–6.9 | Neutral — do more DD |
| D | 4.0–5.4 | Risky |
| F | 2.5–3.9 | High risk |
| NG | < 2.5 | Do not buy |

## CU cost
- **Full run**: ~71 CU
- **Replay from history**: 0 CU
